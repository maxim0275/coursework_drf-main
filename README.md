Инструкции по настройке удаленного сервера

1. Выбрать сервер. Создать сервер с подходящей конфигурацией.
2. Установить Python и зависимости: Установить Python и нужные пакеты для проекта. Обычно это делается с помощью apt-get для Ubuntu.
3.Установить и настроить Gunicorn и Nginx: Gunicorn будет запускать Django-приложение, а Nginx будет работать в качестве обратного прокси-сервера.
4. Настройка SSH: Создать SSH-ключи для безопасного доступа к серверу и закрыть ненужные порты для повышения безопасности.
5. Автоматическая перезагрузка: Настроить Systemd или Supervisor для управления процессами и автоматической перезагрузки приложения при изменениях.
6. Проверка доступа: Убедиться, что приложение доступно по IP-адресу сервера или домену.
